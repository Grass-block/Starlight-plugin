# AGENTS.md for this project

## Dev environment
- Use codegraph CLI command `codegraph ...` to search files
- Write any complete changes to update.md if created by agent.

## Testing instructions
- Do not attempt to add dependencies to gradle, instead ask for confirmation.
- Do not attempt to run or build releases, they are completed not by agents.

## Naming
- Use standard Java naming and tab size.
- Use `f_fieldName`, `c_className` and `m_methodName` for reflect objects.
- Use `var` as possible for var declaration.
