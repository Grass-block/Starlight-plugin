# 快速打开潜影盒 <Badge>starlight-tweaks:portable-shulker-box</Badge>

手持潜影盒时右键空气即可直接打开其物品栏，免去放置再打开的繁琐操作。

## 基本信息

- 命名空间id: `starlight-tweaks:portable-shulker-box`
- 版本: `1.2`
- 是否为内部模块: `否`
- 是否默认开启: `是`
- 是否为未完成[beta]阶段: `否`

## 描述

该模块允许玩家手持任意潜影盒时右键空气直接打开其内部物品栏。当潜影盒被放置时，模块会自动关闭已打开的虚拟会话以防止数据不同步。玩家退出游戏时也会自动清理所有会话。支持所有原版潜影盒变种。

无独立配置项。

无。
