# 手持工作方块 <Badge>starlight-tweaks:portable-functional-blocks</Badge>

手持工作台或末影箱时右键空气即可直接打开其界面，无需放置。

## 基本信息

- 命名空间id: `starlight-tweaks:portable-functional-blocks`
- 版本: `-`
- 是否为内部模块: `否`
- 是否默认开启: `是`
- 是否为未完成[beta]阶段: `否`

## 描述

该模块允许玩家手持工作台（Crafting Table）或末影箱（Ender Chest）时，右键空气直接打开对应的界面，无需将方块放置到世界中。通过子组件（`NetherUpdate`, `VillageUpdate`）可扩展更多手持功能方块的支持。仅响应右键空气事件，不影响对方块本身的交互。

## 可配置项目

无独立配置项。

无。
