# 终末水晶保护 <Badge>starlight-security:end-protect</Badge>

禁止在末地中央岛（主岛）放置末影水晶，以防止末影龙意外复活导致地形破坏。

## 基本信息

- 命名空间id: `starlight-security:end-protect`
- 版本: `-`
- 是否为内部模块: `否`
- 是否默认开启: `否`
- 是否为未完成[beta]阶段: `否`

## 描述

拦截末地维度中在坐标 `(-10, -10)` 到 `(10, 10)` 范围内（主岛范围）右键放置末影水晶的行为。仅对末地（`THE_END`）环境生效，不影响其他维度。

## 可配置项目

无独立配置项。
