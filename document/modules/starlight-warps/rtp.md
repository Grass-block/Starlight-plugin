# 随机传送 <Badge>starlight:rtp</Badge>

随机传送至野外安全位置

## 基本信息

- 命名空间id: `starlight:rtp`
- 版本: `-`
- 是否为内部模块: `否`
- 是否默认开启: `是`
- 是否为未完成[beta]阶段: `否`

## 描述

将玩家随机传送到服务器世界中的安全位置。系统会在指定的半径范围内寻找安全的地面坐标，支持 Y 轴高度限制和多次尝试，以确保玩家不会卡在方块中或出生在半空中。

## 可配置项目

| 路径 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `config.rtp.limit` | int | `10000` | 随机传送最大半径范围（方块） |
| `config.rtp.min-height` | int | `64` | 最低生成 Y 高度 |
| `config.rtp.max-height` | int | `140` | 最高生成 Y 高度 |
| `config.rtp.attempt` | int | `12` | 寻找安全位置的最大尝试次数 |

## 命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/random-tp` (`/rtp`) | `quark.warps.rtp` | 执行随机传送 |
