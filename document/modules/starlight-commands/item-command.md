# 物品指令触发器 <Badge>starlight-commands:item-command</Badge>

将命令绑定到物品上，使用物品时自动执行。

## 基本信息

- 命名空间id: `starlight-commands:item-command`
- 版本: `0.3`
- 是否为内部模块: `否`
- 是否默认开启: `是`
- 是否为未完成[beta]阶段: `否`

## 描述

允许玩家将任意命令绑定到手持物品的PDC（持久化数据容器）中。绑定后，手持该物品右键点击时会自动以玩家身份执行绑定的命令。通过`/item-command none`可清除绑定。该模块使用自定义元数据存储，重启服务器后绑定数据不会丢失。

## 可配置项目

无独立配置项。

## 命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/item-command <命令...>` | - | 将指定命令绑定到手持物品上 |
| `/item-command none` | - | 清除手持物品上的命令绑定 |
