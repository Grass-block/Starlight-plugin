# 「一言」 <Badge>starlight-utilities:hitokoto</Badge>

从「一言」API 获取并展示随机语句。

## 基本信息

- 命名空间id: `starlight-utilities:hitokoto`
- 版本: `1.0.0`
- 是否为内部模块: `否`
- 是否默认开启: `是`
- 是否为未完成[beta]阶段: `否`

## 描述

该模块通过 HTTP 请求调用 `v1.hitokoto.cn` 接口异步获取随机「一言」句子，并在游戏中展示句子内容、作者及出处。为玩家提供轻松有趣的互动体验。

## 可配置项目

无独立配置项。

## 命令

| 命令 | 权限 | 描述 |
|------|------|------|
| `/hitokoto` | 无 | 获取随机「一言」句子 |
