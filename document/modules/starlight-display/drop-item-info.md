# 掉落物高亮信息 <Badge>starlight-display:drop-item-info</Badge>

为掉落物实体显示自定义名称，标记物品数量、ID等信息。

## 基本信息

- 命名空间id: `starlight-display:drop-item-info`
- 版本: `-`
- 是否为内部模块: `否`
- 是否默认开启: `是`
- 是否为未完成[beta]阶段: `否`

## 描述

监听物品掉落事件（玩家丢弃、方块破坏掉落、实体死亡掉落等），将掉落物实体的自定义名称修改为可配置的格式模板，默认显示`{amount}x{id}`样式，方便玩家辨识地面物品。同时处理物品合并事件，更新合并后的显示名称。

## 可配置项目

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `template` | String | 掉落物名称模板，支持`{amount}`、`{id}`、`{translate}`等占位符 |

## 命令

无独立命令。
